How to install Kalam
====================

Requires macOS 14 Sonoma or later. Runs on Apple Silicon and Intel Macs.

Kalam isn't notarized by Apple, so on a new Mac macOS blocks it the first
time. Pick ONE of the two ways below, and use the Terminal fixes if it fails.


OPTION A: Installer package (Kalam-x.x.pkg)
-------------------------------------------
1. Double-click Kalam-x.x.pkg.
2. If macOS says it "can't be opened" or "could not verify" it: click Done,
   open System Settings > Privacy & Security, scroll to Security and click
   "Open Anyway" next to Kalam-x.x.pkg. Enter your password.
3. Follow the installer. Kalam is installed in Applications and opens itself.


OPTION B: Disk image (Kalam-x.x.dmg)
------------------------------------
1. Open the .dmg and drag Kalam onto the Applications folder.
2. Open Kalam from Applications. If macOS blocks it, click Done (don't move
   it to the Bin), then System Settings > Privacy & Security > "Open Anyway".


IF IT STILL FAILS: Terminal commands
------------------------------------
Open Terminal (Applications > Utilities > Terminal), paste a command, press
Return and type your Mac password when asked (nothing shows as you type).

1. The installer package won't open. Install it from Terminal instead
   (change the path if the file isn't in Downloads):

       sudo installer -pkg ~/Downloads/Kalam-*.pkg -target /

2. Kalam is installed but won't open, or macOS says it is "damaged":

       sudo xattr -cr /Applications/Kalam.app && open /Applications/Kalam.app

3. "Open Anyway" doesn't appear, or the .pkg / .dmg itself is blocked:

       xattr -c ~/Downloads/Kalam-*

   then double-click the file again.

4. The daily reminder never shows, or Touch ID unlock keeps failing:

       tccutil reset All local.kalam.Kalam

   then quit and reopen Kalam and allow notifications again
   (System Settings > Notifications > Kalam).

5. Check the Mac is new enough (must say 14 or higher):

       sw_vers -productVersion


AFTER INSTALLING
----------------
Kalam opens on today's page. Press Control-Option-J from any app to jump to
today, type -- then Return for a new sitting, and hold Command to see all
shortcuts. Guided prompts tick themselves automatically on macOS 26 Macs
with Apple Intelligence turned on; elsewhere, tick them by hand.

Your journal is saved in ~/Library/Application Support/Kalam. Use
File > Back Up Everything... before moving to another Mac, then
File > Import... on the new one.

To uninstall (this also deletes your entries, so back up first): quit Kalam
from its menu bar icon, then run

       rm -rf /Applications/Kalam.app ~/Library/Application\ Support/Kalam
